# Urobach Landing Page

React and TypeScript app built with Vite, Tailwind CSS, and Framer Motion.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Tailwind CSS is enabled through the Vite plugin and imported in `src/index.css`.
Use Framer Motion by importing `motion` from `framer-motion`.
